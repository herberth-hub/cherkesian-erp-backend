# Relatório diário do vendedor

**Comando:** `node comercial-inteligente/bin/hc.js relatorio vendedor --responsavel AGT-xxxx --agente vendedor [--base demo] [--hoje AAAA-MM-DD] [--salvar]`
**Quem gera:** hc-vendedor-comercial · **Quem recebe:** gerente comercial

| Seção | Conteúdo gerado |
| --- | --- |
| Dados confirmados | Contatos/atividades do dia, respostas de clientes, propostas em andamento, negociações, fechamentos do dia |
| Estimativas | Pipeline aberto por etapa (valor estimado) |
| Premissas | Probabilidades e limites operacionais |
| Dados ausentes | Oportunidades com campo obrigatório/qualificação faltando |
| Recomendações | Próximos passos até amanhã; definir próximo passo; completar qualificação |
| Decisões pendentes | Aprovações das minhas propostas; solicitações abertas do vendedor |

**Análise do vendedor (texto do agente):** objeções ouvidas, pedidos de apoio ao gerente, pendências de informação do cliente.
Estrutura comum: `_estrutura_comum.md`.
